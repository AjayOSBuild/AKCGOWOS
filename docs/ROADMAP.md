# Project Roadmap

This document outlines the sequential development phases and measurable milestones for the OS project. Progress is measured by working, tested features, not lines of code.

## Development Phases

*   **Phase 0:** Project Architecture (Foundation and rules)
*   **Phase 1:** Boot (UEFI and QEMU initialization)
*   **Phase 2:** Kernel (Core OS foundation)
*   **Phase 3:** Hardware (PCI, USB, Networking, Display)
*   **Phase 4:** Core Services (Service/Device/Session managers)
*   **Phase 5:** Filesystem (VFS, ext4, FAT32, NTFS)
*   **Phase 6:** Graphics (Display server, Compositor)
*   **Phase 7:** Desktop (Original Windows-inspired UI)
*   **Phase 8:** File Explorer (Navigation, File operations)
*   **Phase 9:** Windows Compatibility (EXE/DLL handling, Sandbox)
*   **Phase 10:** Android (APK runtime, Integration)
*   **Phase 11:** Networking (IPv4/v6, DHCP, DNS, Wi-Fi)
*   **Phase 12:** Security (Privilege model, Encryption, Sandbox)
*   **Phase 13:** System Utilities (Task Manager, Settings)
*   **Phase 14:** Developer Environment (Compilers, Toolchains)
*   **Phase 15:** Package Manager (Resolution, Installation, Signatures)
*   **Phase 16:** App Store (GUI, Provider adapters)
*   **Phase 17:** Phone Integration (Discovery, Notification sync)
*   **Phase 18:** Virtualization (QEMU integration, VM UI)
*   **Phase 19:** Installer (ISO, Partitioning, Safe disk operations)
*   **Phase 20:** Update System (Atomic updates, Rollback)
*   **Phase 21:** Recovery (Safe mode, Rollback, Terminal)
*   **Phase 22:** QA (Smoke, Unit, Integration, Regression)

## Milestones

*   **Milestone 1:** QEMU successfully boots the OS.
*   **Milestone 2:** Kernel and basic user space work reliably.
*   **Milestone 3:** Hardware detection works.
*   **Milestone 4:** Core services work.
*   **Milestone 5:** Filesystem works.
*   **Milestone 6:** Graphics/compositor works.
*   **Milestone 7:** Desktop boots.
*   **Milestone 8:** Explorer works.
*   **Milestone 9:** Linux applications work.
*   **Milestone 10:** Windows compatibility subsystem launches selected applications.
*   **Milestone 11:** Android applications work.
*   **Milestone 12:** Networking works.
*   **Milestone 13:** Security architecture is operational.
*   **Milestone 14:** System utilities work.
*   **Milestone 15:** Developer environment works.
*   **Milestone 16:** Package manager works.
*   **Milestone 17:** Sandbox/VM works.
*   **Milestone 18:** Installer works safely in QEMU.
*   **Milestone 19:** Update/recovery system works.
*   **Milestone 20:** Hardware validation begins.
